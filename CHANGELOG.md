# Changelog

## 0.1.0

- Establish FluxScript's restricted declarative Python source API and shared application model.
- Generate web, Android, iOS and standalone CLI source projects.
- Add a read-only source/project analyzer with JSON reports and review findings.
- Add target-specific validation and on-demand upgrade of required Python helper packages.
- Add project export to a timestamped storage directory and ZIP archive.
- Add `guide`, builder, `generate-project`, and remote execution-service commands.
- Add a capability registry, architecture/security documentation, tests and CI workflow.
